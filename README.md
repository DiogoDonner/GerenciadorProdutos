# Gerenciador de Produtos
### Desenvolvido por Diogo Donner

Ao iniciar o programa, o usuário terá acesso a 5 opções, selecionando a desejada pelo número correspondente:

## 1 - Adicionar Item ao Estoque
Solicita o nome do produto a ser adicionado. Após isso, o sistema perguntará se deseja adicionar outro item. Se a resposta for "sim", o processo se repete; caso contrário, retorna ao menu principal.

## 2 - Ver Estoque
Exibe todos os produtos atualmente no estoque.

## 3 - Remover Item do Estoque
Mostra o estoque e solicita o índice do item a ser removido. Após a remoção, o sistema pergunta se deseja remover outro produto. Se "sim", o processo se repete; se "não", retorna ao menu principal.

## 4 - Alterar Produto
Solicita o índice do item a ser alterado e o novo nome. Ao finalizar, pergunta se deseja alterar outro produto. Se "sim", o processo continua; caso contrário, retorna ao menu.

## 5 - Sair
Confirma com o usuário se deseja realmente encerrar o programa. Se confirmado, o sistema é finalizado; caso contrário, retorna ao menu principal.
